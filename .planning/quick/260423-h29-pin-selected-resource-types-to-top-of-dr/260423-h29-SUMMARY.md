# Summary — Quick 260423-h29: Pin selected resource types to top of dropdown

## Outcome

`ResourceTypeSelector` now renders its dropdown with currently-selected types
pinned to the top (in selection order), followed by the rest of `types` in the
caller's original order. Satisfies the Phase 23 UAT T-6.3 C acceptance: with 3
types selected out of 20+, the 3 selected types appear as the first 3 entries
when the dropdown opens.

## Change

`src/components/quality/ResourceTypeSelector.tsx`:

- Import `useMemo`.
- Derive `sortedData` via `useMemo` from (`types`, `value`); pass to
  MultiSelect `data` prop instead of the raw `types`.
- Stale `value` entries not present in `types` are skipped so the dropdown
  only surfaces types the server currently exposes.

```ts
const sortedData = useMemo(() => {
  const selectedSet = new Set(value);
  const selected = value.filter((v) => types.includes(v));
  const rest = types.filter((t) => !selectedSet.has(t));
  return [...selected, ...rest];
}, [types, value]);
```

No prop/API changes; existing tests
(`ResourceTypeSelector.test.tsx` — label + helper text assertions) remain
valid because the UI contract is unchanged.
