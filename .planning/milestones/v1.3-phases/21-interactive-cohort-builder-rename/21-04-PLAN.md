## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser localStorage ↔ app | Migration effect reads/writes storage once; stored snapshots are app-private but PHI-adjacent |
| legacy snapshot → migrateSnapshot | Untrusted shape (may be tampered or corrupt); must validate before use |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-10 | Tampering (XSS via label change) | ResourceTypeSelector label | accept | Mantine `MultiSelect` escapes label/placeholder/description as React text; no dangerouslySetInnerHTML path. Label is a hard-coded string constant. |
| T-21-11 | DoS (migration double-run race) | QualityLayout useEffect | mitigate | `if (existing === null)` guard prevents new-key overwrite; legacy `removeItem` ensures future mounts no-op. Tests `legacy migration` + `migration idempotent` enforce. |
| T-21-12 | DoS (storage quota on migration write) | setItem during migration | mitigate | try/catch silently no-ops; user keeps legacy key and sees label change only. Acceptable fallback — migration completes on next normal save. |
| T-21-13 | Tampering (corrupted snapshot) | migrateSnapshot input | mitigate | Pure function returns `null` for invalid shapes; useTrendsHistory discards null rows (corrupt-payload pattern already shipped at line 58-65). No thrown exceptions. |
| T-21-03 | Information disclosure (patient IDs in logs) | migrateSnapshot error path | mitigate | Returns null without logging; no patient IDs or references emitted to console. |
</threat_model>
