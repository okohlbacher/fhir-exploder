# Plan 30-01: Layout Redesign Integration

## Objective

Port the layout redesign described in `handoff/INSTRUCTIONS.md` from the HTML mockup
into the live Mantine codebase across 7 views, preserving all existing behavior
(routing, hooks, data fetching, tests). **This is a layout-and-styling pass — no
business logic changes.**

Authoritative source: [handoff/INSTRUCTIONS.md](handoff/INSTRUCTIONS.md). Mockup in
`handoff/mockup/` is visual reference only — do not ship mockup code.

## Ground Rules (from INSTRUCTIONS.md)

1. Do not rewrite business logic. Every hook stays as-is.
2. Keep Mantine primitives (`Stack`, `Group`, `Card`, `Table`, `Tabs`). Tighten defaults.
3. Preserve existing tests. Update only when DOM structure genuinely changes; change
   minimally.
4. One commit per step. Order: tokens → Sidebar → Dashboard → Patients → Quality →
   Explorer → Patient detail → Cohorts.
5. Verify after each step: `npm run build` + `npm test`.

## Tasks

### Task 1 — Design tokens (Step 0)

- Create `src/styles/tokens.css` from `handoff/tokens.css`.
- Import once in `src/main.tsx` (after the Mantine style imports).
- Rewrite `src/theme.ts` to use IBM Plex Sans/Mono, `primaryColor: 'indigo'`,
  `primaryShade: 6`, warm-neutral gray ramp, radii (sm/md/lg), and component
  defaults for Card / Table / Button / Tabs per INSTRUCTIONS.md.
- Add the IBM Plex Sans + Mono `<link>` to `index.html` `<head>`.
- Commit: `feat(redesign): add design tokens, IBM Plex fonts, and Mantine theme wiring`

### Task 2 — Sidebar (Step 1)

- Consolidate the two status pills into a single Server `<Card>` (FHIR + terminology
  + URL + profile). Preserve existing click handlers that opened the FHIR and
  terminology modals.
- Update `NAV_ITEMS` so `Cohorts` and `Thresholds` render as children under
  `/quality`. Preserve `useMatch` / `SidebarRow` logic.
- Add indigo 2px left rail + `bg="white"` for active rows.
- Commit: `feat(redesign/sidebar): server card and nested Quality sub-nav`

### Task 3 — Dashboard (Step 2)

- Bump summary strip from 3 cards to 4 (add Patients using `counts['Patient']`).
  Large monospace value (`size={34}` `fw={600}` `ff="var(--font-mono)"`), hint below
  in `size="xs" c="dimmed"`.
- Flip `useDisclosure(false)` → `useDisclosure(true)` for `categoryOpened` and
  `miiOpened` so sections are open by default.
- Category cards: drop `RingProgress`, replace with swatch + big mono count + 3px
  linear bar (`populatedTypes / totalTypes`), existing top-4 type list preserved.
- MII tiles: 4-col on `md`, 2-col on `sm`; label + resource type on left, big number
  on right; `opacity: 0.55` + `—` for empty modules; keep navigate-on-click.
- Commit: `feat(redesign/dashboard): 4-card strip, open-by-default sections, drop RingProgress, MII tile grid`

### Task 4 — Patients list (Step 3)

- Collapse search `<Group>` into a single `<Card p="sm">` filter bar:
  search `TextInput` with `⌘K` `Kbd` in `rightSection`, two 60-px `NumberInput`s for
  age (en-dash separator), gender `Select`, right-pushed Search button.
- Add active-filter chip row below bar (dismissible `Badge`s + "Clear all").
- Table: add leading row-index monospace cell, trailing hover-revealed RAW
  `ActionIcon`, neutral gender chip, 28×28 initials avatar in Name cell.
- Time-range sparkline (CSS-only, 20 bars) next to existing monospace date range —
  constant-weighted for v1.
- Commit: `feat(redesign/patients): card filter bar, chip row, table cols, sparkline`

### Task 5 — Quality overview (Step 4)

- Split toolbar into Tier 1 (scope: `<Card p="sm">` with 3-col `SimpleGrid`) and
  Tier 2 (actions: right-aligned `Group` under title).
- Restyle `OverviewStrip`: uppercase label, big mono % number, tiny
  within/near/breach badge top-right, compact trend arrow under %, 3px fill bar.
- Switch `<Tabs>` to `variant="pills"` with inline counts
  (e.g. `Validation [493]`).
- Add per-type quality matrix card as the default Counts panel
  (Table: type / Complete% / Coverage% / Validation% / References% / Dup / Issues /
  chevron, each % has inline fill bar).
- Commit: `feat(redesign/quality): 2-tier toolbar, strip restyle, pills tabs, per-type matrix`

### Task 6 — Explorer (Step 5)

- Introduce `src/components/explorer/ResourceTypeRail.tsx`: 240-px left rail with
  search `TextInput` and grouped-by-category list
  (reuse `groupByCategory` + `CATEGORY_ORDER`). Monospace type name + dimmed
  monospace count, indigo left rail on active route.
- Update `ExplorerLayout.tsx` to render `<ResourceTypeRail>` alongside `<Outlet>`.
- `ResourceTypeLanding.tsx` / `SearchResultsPage.tsx`: add
  `Explorer › <Category> › <Type>` breadcrumb, promote search/filter to `<Card p="xs">`
  filter bar (field → operator → value + Add filter), applied filters as chips.
  Replace display-mode toggle with a 4-tab `SegmentedControl`
  (Table / Human-readable / Clinical + raw / Developer JSON).
- Commit: `feat(redesign/explorer): ResourceTypeRail, breadcrumbs, card filter, SegmentedControl tabs`

### Task 7 — Patient detail (Step 6)

- Restyle `PatientHeaderCard` as a 3-col grid (64×64 initials avatar / name+badges+
  identifier row / action buttons).
- Add 5-tile `<SimpleGrid cols={5}>` vitals strip below header
  (Resources, Encounters, Conditions, Medications, Time range) fed from existing
  `PatientRelatedResources` data.
- Switch `<Tabs>` in `MiiModuleTabs.tsx` to `variant="pills"`; preserve tab order.
- `ClinicalTimeline` row layout: `[date 110px] [dot rail 24px] [title + sub] [Open →]`
  with 2-px vertical divider behind dots and per-category accent color. Preserve
  `TimelineEntry` / `TimelineAggregateEntry` component logic.
- Commit: `feat(redesign/patient-detail): header grid, vitals strip, pills tabs, timeline restyle`

### Task 8 — Cohorts (Step 7)

- 2-col layout (`grid-template-columns: 1fr 380px`) in `CohortsPage.tsx`.
- Left: existing cohorts table + top-of-card filter `TextInput`.
- Right: live Builder preview card (`<Card>`s from
  `FhirpathCriterionCard` where applicable, match-count badge at top, Dry-run count
  + Save actions at bottom).
- Commit: `feat(redesign/cohorts): split layout with live Builder preview`
