## D-10 Blocker Classification Policy (verbatim from 23-CONTEXT.md)

3. **Cosmetic UX-only failure** (e.g., toast color slightly off, spacing regression) → record as a v1.5+ backlog item in `.planning/todos/pending/` AND note in the UAT file's `## Gaps`; continue execution, do NOT block nyquist flip.

## PHI Sanitization Command (canonical — used by Tasks 2, 3, 7)

Every task that edits a UAT file MUST run the following concrete PHI-sanitization grep before committing. This regex captures (a) tokens/IDs ≥24 alphanumeric chars, (b) `access_token=...` query params, (c) `Bearer ...` auth headers, (d) `Authorization:` / `authorization:` headers, (e) Basic auth base64:

```bash
grep -E '[A-Za-z0-9_-]{24,}|access_token=|Bearer[[:space:]]|[Aa]uthorization:[[:space:]]|Basic[[:space:]][A-Za-z0-9+/=]+' <file> | wc -l
```

**Acceptance:** The command MUST output `0`. If it outputs `>0`, the task FAILS and the executor must redact the matching lines before proceeding. Re-run the command after redaction; it must return `0` before the task can be marked done.
