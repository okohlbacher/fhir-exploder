    **Part A: Create `src/hooks/useConformanceRun.ts`.**

    Follow the same useState-based runner pattern as `useValidationRun.ts` (idle -> running -> complete/cancelled/error) but with these differences:

    1. Creates a `ValueSetCache` instance (once, via useRef).
    2. On `start()`:
       a. Sample resources via `sampleResources(client, resourceType, sampleSize)`
       b. Get profile via `getProfileForType(resourceType)`
       c. If profile has binding elements, expand all needed value sets via `valueSetCache.expand(terminologyClient, url)` before the batch loop. Collect all unique binding.valueSet URLs from the profile elements, then `Promise.all` the expansions.
       d. Build `expandedValueSets: Map<string, Set<string>>` from the cache results (skip null entries).
       e. Batch-iterate resources (same batchSize pattern as useValidationRun):
          - For each resource: call `validateConformance(resource, profile, expandedValueSets)`
          - Convert to NormalizedIssue via `normalizeConformanceIssues`
          - Accumulate issues
          - Update progress
       f. Also run the existing backends (structural + remote) via `resolveBackends` for backwards compatibility. Dedupe across all sources.
    3. Track `terminologyAvailable: boolean` from `valueSetCache.isAvailable()` after expansion attempt.
    4. Return: `{ status, progress, issues: NormalizedIssue[], terminologyAvailable, start, cancel }`.

    State type: `ConformanceRunStatus = 'idle' | 'running' | 'complete' | 'cancelled' | 'error'`.

    The hook needs a `terminologyClient` parameter. Get it by calling `createTerminologyClient(settings)` in the component that uses this hook.

    ```typescript
    export function createConformanceBackend(
      getProfile: (resourceType: string) => StructureDefinition | null,
      expandedValueSets: Map<string, Set<string>>,
    ): ValidationBackend {
      return {
        kind: 'structural' as ValidationBackendKind, // reuses structural kind
        async validate(resource: Resource): Promise<OperationOutcomeIssue[]> {
          const issues = validateConformance(resource, getProfile(resource.resourceType), expandedValueSets);
          // Convert ConformanceIssue to OperationOutcomeIssue for backwards compat
          return issues.map(i => ({
            severity: i.severity === 'info' ? 'information' : i.severity,
            code: i.code === 'required' ? 'required' : 'structure',
            expression: [i.path],
            diagnostics: i.diagnostics,
          }));
        },
      };
    }
    ```
