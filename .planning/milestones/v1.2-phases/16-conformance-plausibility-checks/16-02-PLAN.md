    **Temporal field discovery (D-07):**

    ```typescript
    export interface TemporalPath {
      path: string;
      type: 'dateTime' | 'date' | 'Period' | 'instant';
    }

    export function discoverTemporalPaths(profile: StructureDefinition): TemporalPath[] {
      const elements = profile.snapshot?.element ?? [];
      const temporalTypes = new Set(['dateTime', 'date', 'Period', 'instant']);
      const result: TemporalPath[] = [];
      for (const el of elements) {
        for (const t of el.type ?? []) {
          if (temporalTypes.has(t.code)) {
            result.push({ path: el.path, type: t.code as TemporalPath['type'] });
          }
        }
      }
      return result;
    }
    ```

    **Core check function (D-06):**

    ```typescript
    export interface TemporalIssue {
      path: string;
      checkType: 'future-date' | 'inverted-period' | 'implausible-age' | 'clinical-duration';
      severity: IssueSeverity;
      diagnostics: string;
    }

    export function checkTemporalPlausibility(
      resource: Resource,
      profile: StructureDefinition | null,
      thresholds?: Partial<PlausibilityThresholds>,
      patientBirthDate?: string, // for cross-resource duration checks
    ): TemporalIssue[]
    ```

    Implementation walks discovered temporal paths (profile-based or runtime fallback) and for each resolved value:

    1. **Future date (D-06.1):** `new Date(value).getTime() > Date.now() + 3_600_000` (1h tolerance per Pitfall 5). Severity: `warning`. Applies to all date/dateTime/instant values.

    2. **Period consistency (D-06.2):** For Period-typed fields, check `new Date(period.end) < new Date(period.start)`. Severity: `error`.

    3. **Age plausibility (D-06.3):** Only for `Patient.birthDate`. Calculate age in years: `(Date.now() - birthDate) / (365.25 * 24 * 60 * 60 * 1000)`. Flag if `age < 0` or `age > thresholds.maxAge`. Severity: `error`.

    4. **Clinical duration limits (D-06.4):**
       - For `Encounter.period`: calculate days between start and end. Flag if `> thresholds.maxEncounterDays`. Severity: `warning`.
       - For `Observation.effectiveDateTime` (or effective[x] dateTime): if `patientBirthDate` is provided, flag if observation date < patient birth date. Severity: `error`.

    **Normalization helper:**

    export function normalizeTemporalIssues(

    ): NormalizedIssue[] {
      return issues.map(i => ({

        resourceType: resource.resourceType,
        field: i.path,
        description: `[${i.checkType}] ${i.diagnostics}`,
        severity: i.severity,
      }));
    }
