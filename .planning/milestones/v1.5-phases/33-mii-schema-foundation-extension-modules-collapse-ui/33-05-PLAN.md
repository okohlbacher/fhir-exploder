## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query param (?tab=) → useEffect auto-expand | User-controlled string triggers Collapse state flip via `extensionModules.some((m) => m.key === activeTab)` — pure lookup, no side effect other than `open(true)` |
| useDisclosure state | In-memory only (D-09 — no localStorage, no network) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-05-01 | Tampering | URL `?tab=` param drives deep-link auto-expand | accept | The value is ONLY used in `extensionModules.some((m) => m.key === activeTab)` — a strict equality lookup against compile-time `MII_MODULES`. A crafted URL with `?tab=<arbitrary-string>` simply doesn't match any module and does nothing. No DOM injection, no navigation side effects. |
| T-33-05-02 | Information Disclosure | Extension Collapse visibility | accept | Session-only (`useDisclosure(false)` resets on mount per D-09). No PHI leaked to localStorage, cookies, or network. |
| T-33-05-03 | Denial of Service | Extension panels drop keepMounted → lazy mount → re-fetch on tab switch | accept | This is INTENDED per D-11 — it caps concurrent fetch storm to "only the active extension tab at a time" instead of all 14 on mount. The alternative (keepMounted on 14 extensions) is the DoS vector we're mitigating. Re-fetch on switch is acceptable cost. |

**No new attack surface** — Collapse partition is pure layout; session-only state; no new inputs, network calls, or persistence.
