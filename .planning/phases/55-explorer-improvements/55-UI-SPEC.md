## Spacing Scale

Mantine's built-in spacing scale maps to the 8-point grid. These are the values in active use across the phase:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Stack gap={4} between summary primary and secondary lines (D-01); Card mb={4} above date line; Badge size="sm" internal padding |
| sm | 8px | SimpleGrid spacing="sm" in Cards mode (D-05); Card p="sm" |
| md | 16px | Default Stack/Group padding (existing `p="md"` on outer Stack) |
| lg | 24px | Outer Stack gap="lg" (existing; unchanged) |
| xl | 32px | ResourceTypeLanding outer padding (existing; reference only) |

Exceptions:
- `mb={4}` on the card id/status Group (4px literal — within 4-point grid, acceptable for tight card layout)
- `mt={4}` on card date Text (same reason)
- Summary secondary line: `maxWidth: 380` (table), `maxWidth: 300` (compact) — not spacing values, column width constraints

## Typography

All sizes are Mantine `size` prop values mapping to the existing token scale. The project base is 14px / line-height 1.45 (tokens.css).

| Role | Mantine Size | Approx px | Weight | Line Height | Font | Usage |
|------|-------------|-----------|--------|-------------|------|-------|
| Summary primary — table mode | `sm` | 14px | 600 (fw={600}) | 1.45 (inherited) | IBM Plex Sans | Line 1 of two-line summary cell |
| Summary primary — compact mode | `xs` | 12px | 600 (fw={600}) | 1.45 (inherited) | IBM Plex Sans | Line 1 in compact density rows |
| Summary secondary | `xs` | 12px | 400 (regular) | 1.45 (inherited) | IBM Plex Mono (ff="monospace") | Line 2 of summary cell — dim + mono |
| ID cell | `sm` | 14px | 400 (regular) | 1.45 (inherited) | IBM Plex Mono (ff="monospace") | Resource ID anchor |
| Date cell | `sm` | 14px | 400 (regular) | 1.45 (inherited) | IBM Plex Sans | Date column (table); `xs` in compact |
| Card id line | `xs` | 12px | 400 (regular) | 1.45 (inherited) | IBM Plex Mono | Monospace id at top of card |
| Card primary | `sm` | 14px | 600 (fw={600}) | — (lineClamp={2}) | IBM Plex Sans | Main label on card |
| Card secondary | `xs` | 12px | 400 (regular) | — (lineClamp={1}) | IBM Plex Mono | Dim/mono secondary on card |
| Card date | `xs` | 12px | 400 (regular) | 1.45 (inherited) | IBM Plex Sans | Bottom date line on card |
| Empty state heading | `lg` | 18px | 600 (fw={600}) | 1.2 | IBM Plex Sans | "No resources found" (existing; unchanged) |
| Empty state body | `sm` | 14px | 400 | 1.45 | IBM Plex Sans | Help text under empty heading |

Typography rules:
- Exactly 2 weights in use: 400 (regular) and 600 (semibold). No 500, no 700.
- Monospace (`ff="monospace"`) is IBM Plex Mono via `fontFamilyMonospace` in theme.ts. Apply to: resource IDs, summary secondary lines, card id lines.
- Summary primary (`fw={600}` + `size="sm"`) makes the bold line scannable at a glance. Secondary (`c="dimmed"` + `ff="monospace"` + `size="xs"`) recedes visually.

## Color

Source of truth: `src/styles/tokens.css` + `src/theme.ts` (primaryColor: 'indigo', primaryShade: 6).

| Role | Value / Token | Usage |
|------|--------------|-------|
| Dominant (60%) | `--bg` (`oklch(99% 0.004 85)`) | Page background; table row background |
| Secondary (30%) | `--panel` (`#ffffff`) + `--panel-2` (`oklch(97.2% 0.005 85)`) | Cards (`Paper withBorder`), striped table rows, table hover state |
| Accent (10%) | `--accent` (`oklch(54% 0.17 262)` — indigo-6) | Focus ring on focused table row (`--accent-ring`); SegmentedControl selected segment |
| Status: success | Mantine `green` (`color="green"`) | Badge for `active` / `completed` status values |
| Status: neutral | Mantine `gray` (`color="gray"`) | Badge for all other status values |
| Dimmed text | `c="dimmed"` (Mantine maps to `--mantine-color-dimmed`) | Summary secondary line; card id, date, secondary |
| Destructive | `--bad` (`oklch(58% 0.16 22)`) | Not used in this phase — no destructive actions |

Accent reserved for:
- Focused table row outline (`outline: 2px solid var(--accent-ring)`) — the single source of keyboard focus feedback in the table
- SegmentedControl active segment indicator (Mantine handles this internally via `primaryColor: 'indigo'`)

No new semantic colors introduced in Phase 55. Badge colors (`green` / `gray`) are carried forward from the existing implementation (line 490–497 of SearchResultsPage.tsx).

## Component Specifications

### EXPL-01: Two-line Summary Cell (source: D-01)

Replace the single `<Anchor>` in the Summary `Table.Td` with an `<Anchor>` wrapping a `<Stack gap={4}>` (xs token, 4px — on-grid minimum):

```
<Anchor
  href={`/explorer/${r.resourceType}/${r.id}`}
  onClick={(e) => { e.preventDefault(); navigate(...); }}
  style={{ display: 'block', maxWidth: 400 }}
>
  <Stack gap={4}>
    <Text fw={600} size="sm">{primary}</Text>
    {secondary && (
      <Text
        c="dimmed"
        ff="monospace"
        size="xs"
        truncate="end"
        style={{ maxWidth: 380 }}
      >
        {secondary}
      </Text>
    )}
  </Stack>
</Anchor>
```

- `secondary` line is rendered ONLY when `summarizeResource(r).secondary` is a non-empty string.
- In compact mode: primary uses `size="xs"`, secondary `maxWidth` reduces to 300.
- The outer `Anchor` preserves the existing click-to-navigate behavior and hover underline on the primary line only.

### EXPL-02: Density SegmentedControl (source: D-02, D-03, D-04, D-05, D-10)

**Placement:** Replace the current `<Group justify="flex-end">` Export block with:

```
<Group justify="space-between" align="center">
  <SegmentedControl
    value={density}
    onChange={(v) => setDensity(v as 'cards' | 'table' | 'compact')}
    data={[
      { value: 'cards', label: 'Cards' },
      { value: 'table', label: 'Table' },
      { value: 'compact', label: 'Compact' },
    ]}
    size="xs"
  />
  <Menu ...>{/* existing Export menu — unchanged */}</Menu>
</Group>
```

Shown only when `resources.length > 0` (same condition gate as the Export button).

**Persistence:**

```ts
const [density, setDensity] = useLocalStorage<'cards' | 'table' | 'compact'>({
  key: 'explorer.density.v1',
  defaultValue: 'table',
  getInitialValueInEffect: false,
});
```

Import: `useLocalStorage` from `@mantine/hooks` (already a project dependency; same pattern as `ResourceTypeLanding.tsx` line 28).

**Table mode** (`density === 'table'`): current `<Table striped highlightOnHover withTableBorder>` with no changes except the two-line summary cell from EXPL-01.

**Compact mode** (`density === 'compact'`): same `<Table>` but:
- Add `verticalSpacing="xs"` prop (note: theme.ts already sets `Table` defaultProps `verticalSpacing: 'xs'` — confirm this prop override works as expected; if theme default is already xs, compact mode may need `verticalSpacing="2"` or a custom style to tighten further).
- Primary text in summary: `size="xs"` (down from `sm`).
- Date cell text: `size="xs"`.
- Summary secondary `maxWidth`: 300 (down from 380).

**Cards mode** (`density === 'cards'`): replace `<Table>` with `<SimpleGrid cols={{ base: 1, sm: 2, lg: 3 }} spacing="sm">`.

Each card:

```
<Paper
  key={r.id}
  withBorder
  p="sm"
  radius="sm"
  style={{ cursor: 'pointer' }}
  tabIndex={0}
  onClick={() => navigate(`/explorer/${r.resourceType}/${r.id}`)}
  onFocus={() => setFocusedResource(r)}
  onBlur={(e) => {
    const next = e.relatedTarget as Node | null;
    const grid = (e.currentTarget as HTMLElement).closest('.mantine-SimpleGrid-root');
    if (!next || !grid?.contains(next)) setFocusedResource(null);
  }}
>
  <Group justify="space-between" mb={4}>
    <Text ff="monospace" size="xs" c="dimmed" truncate="end" style={{ maxWidth: 180 }}>
      {r.id}
    </Text>
    {status && <Badge size="sm" variant="light" color={statusColor}>{status}</Badge>}
  </Group>
  <Text fw={600} size="sm" lineClamp={2}>{primary}</Text>
  {secondary && (
    <Text c="dimmed" ff="monospace" size="xs" lineClamp={1}>{secondary}</Text>
  )}
  <Text size="xs" c="dimmed" mt={4}>{date}</Text>
</Paper>
```

Cards are focusable (`tabIndex={0}`) and set `focusedResource` on focus — J shortcut works identically in all three modes.

## Interaction Contract

| Interaction | Trigger | Response |
|-------------|---------|----------|
| Switch density | SegmentedControl click | Re-render results area in selected mode; persist to localStorage; no flicker (getInitialValueInEffect: false) |
| Row focus (table/compact) | Tab or mouse focus on `<Table.Tr>` | `focusedResource` set; indigo outline (`--accent-ring`) appears on row |
| Card focus | Tab or mouse focus on `<Paper>` | `focusedResource` set; Mantine focus ring appears |
| Row blur (table) | Focus leaves tbody | `focusedResource` cleared (via relatedTarget check against closest `tbody`) |
| Card blur | Focus leaves SimpleGrid | `focusedResource` cleared (via relatedTarget check against closest `.mantine-SimpleGrid-root`) |
| J key | Any mode, row/card focused | `openPeek(focusedResource, originElement)` |
| J key | Any mode, nothing focused | Silent no-op |
| J key | SegmentedControl focused | Skipped (radio input — useShortcuts guard fires) |
| Click row/card | Mouse click | `navigate(/explorer/:type/:id)` |
| Click Export | Menu.Target click | Export menu opens (unchanged) |

### Focus Ring Specification

Table rows: `outline: 2px solid var(--accent-ring)` + `outlineOffset: '-1px'` (existing implementation — carried forward unchanged).

Cards: Mantine default focus ring via `Paper tabIndex={0}`. If custom ring is needed, apply same `var(--accent-ring)` pattern as table rows via inline style or CSS module.

### Keyboard Navigation

| Key | Scope | Action |
|-----|-------|--------|
| Tab | Table / Cards | Move focus between rows/cards |
| Enter / Click | Focused row or card | Navigate to detail page |
| J | Focused row or card | Open JSON peek drawer |
| J | SegmentedControl focused | No-op (radio input guard) |

Arrow-key navigation between cards is explicitly deferred (55-CONTEXT.md Deferred section).
