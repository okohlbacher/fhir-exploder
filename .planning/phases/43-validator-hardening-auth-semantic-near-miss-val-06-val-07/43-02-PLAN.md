- Imports: `import type { Parameters } from '@medplum/fhirtypes'; import type { TerminologyResolver } from '../terminology/TerminologyResolver';`
- Constants: `MAX_DEPTH = 3`, `MAX_NODES = 50`, `MAX_SUGGESTIONS = 10` (D-08, D-09 — non-configurable in v1.6)
- Export `interface NearMissSuggestion { system: string; code: string; display: string; relation: 'parent' | 'child' | 'sibling'; depth: number; }`
- Export `async function walkNearMisses(system: string, invalidCode: string, resolver: TerminologyResolver): Promise<NearMissSuggestion[]>`
- BFS algorithm:
  1. If `!resolver.client` → return `[]` (D-12 silent fallback).
  2. Seed: `$lookup?system={system}&code={invalidCode}&property=parent&property=child` to get immediate parents+children.
  3. For each parent → enqueue with `relation='parent'`, depth=1; for each child → enqueue with `relation='child'`, depth=1.
  4. BFS dequeue while queue non-empty AND `totalNodes < MAX_NODES`:
     - For each node: call `resolver.lookupDisplay(node.system, node.code)` (LRU-cached) to get the display string.
     - Push to `ancestors[]` (if relation === 'parent') or `descendants[]` (if relation === 'child').
     - If `node.depth < MAX_DEPTH`: fetch `$lookup` with property={node.relation} (only walk same axis to keep parents-only / children-only branches).
     - For each new code returned: skip if already in `visited` Set (`${system}|${code}` key); else enqueue.
  5. Sort `ancestors` by depth ASC then display ASC; sort `descendants` by depth ASC then display ASC.
  6. Return `[...ancestors, ...descendants].slice(0, MAX_SUGGESTIONS)`.

**Step 2 — `extractRelations` helper.** Per Pitfall 3, fall through `valueCode → valueString → valueCoding.code`:
```typescript
function extractRelations(p: Parameters): Array<{ value: string; role: 'parent' | 'child' }> {
  const out: Array<{ value: string; role: 'parent' | 'child' }> = [];
  for (const prop of p.parameter ?? []) {
    if (prop.name !== 'property') continue;
    const codePart = prop.part?.find((q) => q.name === 'code')?.valueCode;
    const valuePart = prop.part?.find((q) => q.name === 'value');
    const value = valuePart?.valueCode ?? valuePart?.valueString ?? valuePart?.valueCoding?.code;
    if ((codePart === 'parent' || codePart === 'child') && value) {
      out.push({ value, role: codePart });
    }
  }
  return out;
}
```
