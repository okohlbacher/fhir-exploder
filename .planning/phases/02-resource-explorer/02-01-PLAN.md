|----------|-------------|
| URL params -> SearchRequest | User-controlled URL params parsed into FHIR search query |
| JSON data -> DOM rendering | FHIR resource data rendered as syntax-highlighted JSON |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | useSearchState URL parsing | mitigate | Use Medplum's parseSearchRequest (sanitizes FHIR search params), never construct raw URLs from user input |
| T-02-02 | Tampering | JsonSyntaxHighlight | mitigate | Render all JSON content via React's textContent/children (JSX escaping), never use dangerouslySetInnerHTML. Tokenizer operates on string values only. |
| T-02-03 | Information Disclosure | ExplorerLayout | accept | MedplumClient already in memory; layout just provides it to children via context. No new exposure. |
</threat_model>
