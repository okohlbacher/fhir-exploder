         function handleReferenceClick(e: React.MouseEvent) {
           const target = e.target as HTMLElement;
           const anchor = target.closest('a[href]') as HTMLAnchorElement | null;
           if (!anchor) return;
           const href = anchor.getAttribute('href') || '';
           // Match FHIR reference pattern: ends with /ResourceType/id

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| FHIR resource content -> DOM | Server-returned resource data rendered in three view modes |
| Reference href -> navigation | Extracted reference targets used for in-app routing |
| Keyboard input -> tab switching | Keydown events trigger display mode changes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Tampering | ResourceDetailPage reference interception | mitigate | Validate extracted reference matches FHIR pattern `[A-Z][a-zA-Z]+/[a-f0-9-]+` before navigation. Never navigate to arbitrary URLs. |
| T-02-09 | Tampering | HumanReadableView / ClinicalRawView via ResourceTable | accept | ResourceTable from @medplum/react uses React's safe rendering (no innerHTML). Medplum handles FHIR data type display safely. |
| T-02-10 | Information Disclosure | DeveloperJsonView shows full resource | accept | By design — this is a FHIR explorer. User has server access already. JSON view shows what they can already see via API. |
| T-02-11 | Spoofing | Breadcrumb trail manipulation | mitigate | Breadcrumb entries only added via push() from reference clicks with validated patterns. Trail is in-memory state, not from URL. |
</threat_model>
