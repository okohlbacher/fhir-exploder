<objective>
Fix the shared connection state bug that blocks the entire Resource Explorer.

Purpose: ExplorerLayout calls useConnection() which creates independent local state, so it never sees the connection established on the dashboard. This makes the explorer permanently show "Not connected". The fix is to lift connection state into a React context provider so all routes share a single connection instance.

Output: ConnectionContext provider, refactored useConnection, updated App.tsx and consumers.
</objective>
