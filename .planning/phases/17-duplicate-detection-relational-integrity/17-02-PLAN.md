    3. Compute `pct` from `run.progress`
    4. Filter issues by category: `run.issues.filter(i => i.description.startsWith('[${categoryFilter}]'))` when not "all"
    5. Count issues per category for badges

    Layout (per I-02 in UI-SPEC):
    - `<Stack gap="md">`
    - Controls `<Paper withBorder p="md" radius="sm">` containing `<Group align="flex-end" gap="md">`:
      - `<Select label="Resource type" data={typeOptions} value={resourceType} onChange={...} searchable style={{ minWidth: 240 }} />`
      - `<Select label="Category" data={CATEGORY_OPTIONS} value={categoryFilter} onChange={...} style={{ minWidth: 200 }} />`
        where CATEGORY_OPTIONS = `[{value:"all",label:"All checks"},{value:"patient-duplicate",label:"Patient duplicates"},{value:"content-hash",label:"Content hash duplicates"}]`
      - `<Button variant="filled" onClick={run.start} disabled={run.status === 'running'}>Run duplicate checks</Button>`
      - Cancel button when running: `<Button variant="subtle" color="red" onClick={run.cancel} leftSection={<IconX size={14} />}>Stop duplicate check</Button>`

    - Running state: `<Paper withBorder p="sm" radius="sm"><Stack gap="xs" aria-live="polite"><Text size="sm">` with progress message (per Copywriting Contract):
      - "Matching patients ({current}/{total})..." or "Hashing {resourceType} resources ({current}/{total})..."
      - `<Progress value={pct} animated />`

    - Cancelled state: `<Alert variant="light" color="yellow" icon={<IconAlertTriangle size={20} />}>Duplicate check cancelled at {current}/{total}. Results below reflect completed resources only.</Alert>`

    - Error state: `<Alert variant="light" color="red" icon={<IconAlertTriangle size={20} />}>Failed to run duplicate checks. Check your FHIR server connection and try again.</Alert>`

    - Complete with 0 issues: `<Alert variant="light" color="green" icon={<IconCheck size={20} />} title="No duplicates detected">No duplicate patients or resources found in the sample. Increase the sample size to check more resources.</Alert>`

    - Complete/cancelled with issues: `<Stack gap="xs">`:
      - `<Text size="sm">{N} patient duplicate clusters ({M} patients involved)</Text>` with `<Badge color="orange" variant="light" size="sm">patient: {N}</Badge>`
      - `<Text size="sm">{N} content hash clusters in {resourceType} ({M} resources involved)</Text>` with `<Badge color="violet" variant="light" size="sm">hash: {N}</Badge>`
      - If `run.skippedPatients > 0`: `<Text size="sm" c="dimmed">({K} patients skipped -- missing name or birthDate)</Text>`
