```typescript
import { createContext, useContext, useMemo, useState, type ReactNode } from 'react';

export interface QualityMetricsContextValue {
  /** Arithmetic mean of per-type completeness percentages (0-100). Undefined until Plan 03 sets. */
  overallCompleteness: number | undefined;
  /** Arithmetic mean of per-type coverage percentages (0-100). Undefined until Plan 04 sets. */
  overallCoverage: number | undefined;
  setCompleteness: (value: number | undefined) => void;
  setCoverage: (value: number | undefined) => void;
}

const Ctx = createContext<QualityMetricsContextValue | null>(null);

export function QualityMetricsProvider({ children }: { children: ReactNode }) {
  const [overallCompleteness, setCompleteness] = useState<number | undefined>(undefined);
  const [overallCoverage, setCoverage] = useState<number | undefined>(undefined);
  const value = useMemo(
    () => ({ overallCompleteness, overallCoverage, setCompleteness, setCoverage }),
    [overallCompleteness, overallCoverage],
  );
  return <Ctx.Provider value={value}>{children}</Ctx.Provider>;
}

export function useQualityMetrics(): QualityMetricsContextValue {
  const ctx = useContext(Ctx);
  if (!ctx) {
    // Graceful fallback for components rendered outside the provider (e.g., isolated tests).
    // Plans 03/04 setters become no-ops; OverviewStrip shows em-dashes as before.
    return {
      overallCompleteness: undefined,
      overallCoverage: undefined,
      setCompleteness: () => {},
      setCoverage: () => {},
    };
  }
  return ctx;
}
```

Rollup rule lock (CRITICAL — also document in the 05-01-SUMMARY.md output):
- **`overallCompleteness`** = arithmetic mean of `report.populated / report.total * 100` across every type where the report is a settled PerTypeCompletenessReport AND `report.total > 0`. Types still loading, errored, or with no bundled profile (total === 0) are EXCLUDED from the denominator.
- **`overallCoverage`** = arithmetic mean of `report.systemCode / report.totalCodedFields * 100` across every type where the report is a settled PerTypeCoverageReport AND `report.totalCodedFields > 0`.
- **Why arithmetic mean, not weighted-by-count:** the MII Kerndatensatz frames each module as equal-weight (Diagnose, Labor, Medikation, etc. each contribute the same clinical signal). Weighting by count would let a high-volume type like Observation dominate and mask gaps in lower-volume but clinically critical types. Plans 03/04 must compute their rollup with this rule and call the setter with a rounded integer (Math.round).

**5. `src/components/quality/SampleSizeControl.tsx`** — NumberInput + hook:
```typescript
import { NumberInput } from '@mantine/core';
import { useLocalStorage, useDebouncedValue } from '@mantine/hooks';

const KEY = 'quality.sampleSize.v1';
const DEFAULT = 100;
const MIN = 10;
const MAX = 1000;

export function useSampleSize(): [number, (n: number) => void] {
  const [raw, setRaw] = useLocalStorage<number>({ key: KEY, defaultValue: DEFAULT });
  const clamped = Math.max(MIN, Math.min(MAX, Number(raw) || DEFAULT));
  return [clamped, (n: number) => setRaw(Math.max(MIN, Math.min(MAX, Math.floor(n))))];
}

export function SampleSizeControl({ value, onChange }: { value: number; onChange: (n: number) => void }) {
  const [debounced] = useDebouncedValue(value, 500);
  // note: the panel components use useSampleSize() directly; this control wraps the NumberInput only.
  // onChange fires immediately; consumers debounce if they want (Completeness hook invalidates on debounced change).
  return (
    <NumberInput
      label="Sample size"
      description="First N resources of each type are inspected. Increase for accuracy; decrease for speed."
      min={MIN}
      max={MAX}
      step={10}
      value={value}
      onChange={(v) => onChange(typeof v === 'number' ? v : Number(v) || DEFAULT)}
      aria-label="Sample size"
    />
  );
}
```
Note: debouncing lives inside the Wave-2 hooks (useCompletenessReport, useCodingCoverage), not inside the control. The control just exposes the raw live value; downstream hooks use useDebouncedValue on the sample-size input in their own effects. This keeps the control stateless.
