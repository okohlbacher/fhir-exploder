## Spacing Scale

Declared values (must be multiples of 4). Mapped to Mantine's spacing tokens via `createTheme()`:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge internal padding |
| sm | 8px | Compact element spacing, sidebar icon-to-label gap |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, sidebar section breaks |
| xl | 32px | Layout gaps between main content areas |
| 2xl | 48px | Sidebar width padding, major section breaks |
| 3xl | 64px | Page-level top/bottom margin |

Exceptions: Sidebar width is 240px (not a spacing token -- layout constant). Minimum touch target for Connect button is 36px height (Mantine Button default `md` size).

## Typography

All sizes use Mantine's default font scale, configured via `createTheme()`:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.55 |
| Label | 14px | 500 (medium) | 1.45 |
| Heading (h2/h3) | 20px | 600 (semibold) | 1.3 |
| Display (h1/page title) | 28px | 700 (bold) | 1.2 |

Source: Mantine 8 default `fontSizes` are xs=12, sm=14, md=16, lg=18, xl=20. We use `sm` (14px) for body to maximize data density on this data-heavy, desktop-only tool (REQUIREMENTS.md: "optimize for 1200px+ screens"). Headings use `xl` (20px). Page titles at 28px for clear hierarchy on the landing/dashboard page.

Note: Two primary weights (400 and 600) cover 90% of usage. Weight 500 reserved strictly for form labels and sidebar navigation items. Weight 700 reserved strictly for page-level display headings (h1).

## Color

Using Mantine's default light theme (D-03) with minimal customization:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#ffffff` (white) | Page background, main content area |
| Secondary (30%) | `#f8f9fa` (gray.0) | Sidebar background, card surfaces, table header rows, settings display area |
| Accent (10%) | `#228be6` (blue.6, Mantine default primary) | Connect button, active sidebar item highlight, connection status "connected" dot, clickable resource type links |
| Destructive | `#fa5252` (red.6) | Connection error icon, error state borders, "disconnected" status dot |

Accent reserved for:
1. The "Connect" button (primary CTA)
2. Active sidebar navigation item indicator (left border or background highlight)
3. Connection status dot when connected (green variant: `#40c057` / green.6)
4. Clickable resource type names in the CapabilityStatement list
5. Link text color for future Phase 2 navigation targets

Additional semantic colors:
- Warning: `#fd7e14` (orange.6) -- used only for the "using default settings" warning banner (D-06)
- Success/Connected: `#40c057` (green.6) -- connection status dot when connected
- Error/Disconnected: `#fa5252` (red.6) -- connection status dot when errored/disconnected
- Neutral/Idle: `#adb5bd` (gray.5) -- connection status dot when not yet connected

### Resource Type List (D-07, D-08, D-09)

- Grouped by FHIR category using Mantine `Accordion` or sectioned list
- Each group: category name as section header (semibold, 20px)
- Each resource type row: resource name (link-styled), count badge (lazy-loaded with `Loader` size="xs" until resolved), search param count, operations count
- Use Mantine `SimpleGrid` with 2-3 columns for resource types within each group

## Interaction States

### Connection Flow (D-11)

| State | Visual |
|-------|--------|
| Not connected (initial) | Server info card visible. Connect button enabled (accent blue, filled variant). Sidebar dot: gray. |
| Connecting | Connect button shows Mantine `Loader` inside button, button disabled. Sidebar dot: gray with pulse animation (CSS). |
| Connected | Connect button changes to "Connected" (green, outline variant, disabled). Server info card shows server name/version from CapabilityStatement. Sidebar dot: green. Resource type list appears below. |
| Connection error | Connect button re-enabled. Error alert appears below the card (Mantine `Alert` component, red variant). Sidebar dot: red. |

### Loading States (CONN-05)

| Context | Indicator |
|---------|-----------|
| Initial connection | Loader inside Connect button |
| CapabilityStatement parsing | Mantine `Skeleton` placeholders for resource type list |
| Per-resource-type counts (D-09) | Mantine `Loader` size="xs" inline next to each resource type name, replaced by count `Badge` when resolved |
| Full page load | Mantine `LoadingOverlay` on the main content area (used sparingly) |

### Error States (CONN-04)

| Error | Display |
|-------|---------|
| Server unreachable | Mantine `Alert` variant="light" color="red" icon={IconAlertCircle}. Title: "Cannot reach FHIR server". Body: error details + suggestion. |
| Invalid response | Same alert pattern. Title: "Unexpected server response". Body: HTTP status + suggestion to verify URL. |
| Auth failure | Same alert pattern. Title: "Authentication failed". Body: auth mode used + suggestion to check credentials in settings.yaml. |
| settings.yaml missing | Mantine `Alert` variant="light" color="orange". Title: "Using default settings". Body: "No settings.yaml found. Using localhost:8080 with open auth. Create settings.yaml to configure." |
