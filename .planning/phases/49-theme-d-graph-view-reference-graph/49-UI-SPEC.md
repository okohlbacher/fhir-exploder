# Phase 49 — UI Design Contract

> Visual and interaction contract for the standalone "Graph" button + lazy `/explorer/:type/:id/graph` route.
> Generated by gsd-ui-researcher; verified by gsd-ui-checker.
>
> **Scope guard:** Phase 49 ships ONLY the standalone Graph button + lazy graph view (CONTEXT D-01).
> The 4-mode resource shell (`Summary | Human | Graph | JSON`) from `design_handoff_v1.7_navigation/`
> is **deferred** to a follow-up phase. This spec applies to the button + lazy view + their immediate
> chrome (depth slider, Controls, MiniMap, empty/loading/truncation states), nothing else.

## Typography

### Phase-49 invariant statement

> **Phase 49 introduces 2 font weights (400 regular for body, 500 medium for labels). The page
> heading uses the Mantine `Title` primitive's theme-inherited weight — this is
> `src/theme.ts` default (no `headings:` override in the project's `createTheme()` config),
> NOT a Phase-49 introduction. No `fw={700}+` is hand-applied anywhere in Phase 49 source.**

This means Phase 49 source code declares exactly two weight values (`fw={500}` for `<Text>` labels;
nothing for body which defaults to 400). The page heading's weight is whatever
`<Title order={2}>` resolves to via Mantine's theme cascade — it is inherited, not a Phase 49
contract decision.

### Font weights — introduced vs. inherited

| Source | Weight | Where it appears |
|--------|--------|------------------|
| **Introduced by Phase 49** | 400 (regular, default) | Body text everywhere — `<Text size="sm">`, `<Text size="xs">`, tooltip body, alert body, mono labels |
| **Introduced by Phase 49** | 500 (medium) | `<Text size="sm" fw={500}>` for graph node primary labels and depth slider mark labels |
| **Inherited from `src/theme.ts` / Mantine defaults** | (whatever `<Title order={2}>` resolves to) | Page heading: `Reference graph`. Phase 49 source writes `<Title order={2}>` only — no `fw=` prop, no inline style. The rendered weight is determined by Mantine's `--mantine-h2-font-weight` CSS variable + any project-level override. Phase 49 does NOT override or duplicate this. |

### Font sizes & line heights

Phase 49 uses 4 sizes — within the GSD ceiling.

| Role | Mantine prop | Resolved size | Weight source | Line height | Phase 49 usage |
|------|--------------|---------------|---------------|-------------|----------------|
| Body | `<Text size="sm">` | 14px | introduced 400 | 1.55 | Tooltip body (`secondary` from `summarizeResource`); Alert body copy (empty / truncation) |
| Label | `<Text size="sm" fw={500}>` | 14px | introduced 500 | 1.45 | Graph node primary label (`summarizeResource(target).primary`); depth slider mark labels |
| Meta / mono | `<Text size="xs" c="dimmed">` (Plex Mono via `ff="monospace"` or `.mono` util) | 12px | introduced 400 | 1.4 | Resource type label inside `ResourceGraphNode` (e.g. `OBSERVATION`); edge label (FHIR field name e.g. `subject`); node-count meta in toolbar |
| Heading (page) | `<Title order={2}>` | 24px | **inherited from theme `Title` primitive** | 1.2 | Graph view page heading: "Reference graph — {ResourceType}/{id}". Phase 49 emits `<Title order={2}>` with no weight prop — actual weight resolves via Mantine's theme cascade. |

### Typography notes

- **No `c="red"` / no semantic color on text by default** — destructive copy is delivered via `<Alert color="red">`, not red text.
- **Edge labels use IBM Plex Mono at 11px** (per RESEARCH §"Exact CSS bridge" — `.react-flow__edge-text { font-family: var(--mantine-font-family-monospace); font-size: 11px }`). The mono treatment makes FHIR field names (`subject`, `has-member`, `value-quantity`) read as code identifiers, distinct from the prose node labels.
- **Node primary label is `<Text size="sm" fw={500}>`** with `lineClamp={1}` — single-line, 220px-wide nodes truncate via ellipsis. The full text remains accessible via the Mantine Tooltip with `secondary`.
- **Resource-type label inside the node is uppercase** (matches design handoff `concept.jsx` pattern) — applied via `tt="uppercase"` Mantine prop, NOT a CSS `text-transform` override.
- **No bold body text introduced by Phase 49** — only `fw={500}` for labels. The page heading's weight is inherited from the `Title` primitive (see "introduced vs. inherited" table above), not hand-applied. No `fw={700}+` in any Phase 49 source file.

## Color

Mantine 8 theme already locks the 60/30/10 split via `primaryColor: 'indigo'` + warm-neutral gray ramp (`src/theme.ts:122-136`). Phase 49 inherits this and adds **zero new colors**.

| Role | Token (light) | Token (dark) | Usage in Phase 49 |
|------|---------------|--------------|-------------------|
| Dominant (60%) | `var(--mantine-color-body)` → `#fff` | `var(--mantine-color-dark-7)` | Page background; graph canvas background; node Card background |
| Secondary (30%) | `var(--mantine-color-default)` → near-white | `var(--mantine-color-dark-6)` | Toolbar `<Paper>` background; Controls + MiniMap chrome background; below-canvas Alert background (with `variant="light"`) |
| Accent (10%) | `var(--mantine-color-indigo-6)` | (same ramp) | **Reserved-for list below** |
| Muted neutral | `var(--mantine-color-gray-5)` (light) / `var(--mantine-color-dark-2)` (dark) | (auto via Mantine) | Edge stroke; edge labels' `dimmed` text; minimap mini-node fill |
| Border | `var(--mantine-color-default-border)` → `gray-4` (light) / `dark-4` (dark) | (auto) | Node Card border (non-root); Paper borders; Controls button borders |

### Accent (`indigo-6`) reserved for — explicit list:

1. **Root-node accent border** on `<ResourceGraphNode>` when `data.isRoot === true`. Non-root nodes use `var(--mantine-color-default-border)`. The accent border is **2px**, non-root borders are **1px** — depth-of-information cue, not just color.
2. **Graph button** on `ResourceDetailPage` toolbar — Mantine `<Button variant="light" color="indigo">` (`light` keeps it visually subordinate to the existing primary actions; `color="indigo"` resolves to indigo-6 fill on hover via the `light` variant's hover wash).
3. **Depth slider thumb + filled track** — Mantine `<Slider color="indigo">` (default; the slider auto-uses `theme.primaryColor`).
4. **React Flow controls' active state** — `--xy-controls-button-color-active` mapped to `var(--mantine-color-indigo-6)` via `graph.module.css`.
5. **Selected-edge stroke** — `--xy-edge-stroke-selected-default: var(--mantine-color-indigo-6)`. Selection is a side-effect of clicking a node's outgoing/incoming edge in React Flow; we do not surface a "select edge" affordance, but the visual contract still applies.

### Destructive color — NOT used in Phase 49

There is no destructive action surface (no delete, no resource mutation). Error states (D-14 silent fallback per-fetch; D-13 alternate alert when ALL fetches fail) use **Mantine `Alert color="gray" variant="light"`** for empty + `Alert color="red" variant="light"` only for the all-fetches-failed case. Per-fetch errors are silent (console only).

### Edge-color contract

| Edge type | Stroke | Stroke width | Marker |
|-----------|--------|--------------|--------|
| Outgoing reference | `var(--mantine-color-gray-5)` light / `var(--mantine-color-dark-2)` dark via `--xy-edge-stroke-default` | 1.6 px | Default React Flow arrowhead (`MarkerType.ArrowClosed`), same color as stroke |
| Incoming reference | Same neutral as outgoing | 1.6 px | Same arrowhead — direction encodes "X references Y", arrowhead points AT the target (D-10 spec). |
| Selected edge (transient) | `var(--mantine-color-indigo-6)` | 2.0 px (React Flow default for selected) | Same |

**No dashed-vs-solid distinction between in/out** (the design handoff's `concept.jsx` shows dashed-incoming, but with dagre's TB layout + arrowheads, direction is already encoded by edge geometry; dashed adds visual noise. Decision locked: solid for all, arrowhead carries direction).

## Interaction Contracts

### Click / hover

| Surface | Trigger | Action |
|---------|---------|--------|
| Graph button (`ResourceDetailPage`) | Click | `navigate(/explorer/${type}/${id}/graph)` (router-based; no full reload). Browser history pushed; back button returns to resource detail. |
| Graph node (any) | Click | `navigate(/explorer/${target.resourceType}/${target.id})` (D-05). Single click; no double-click intermediary; no selection state preserved. |
| Graph node | Hover | Mantine `Tooltip` with `summarizeResource(target).secondary` shows after default delay; positioned `right` with arrow (D-07). Disabled when `secondary` is `undefined`. |
| Graph node (root) | Hover | Same Tooltip behavior — root node has `secondary` like any other; the only differentiation is the accent border (visual). |
| Depth slider | Drag / arrow keys | Re-fetches BFS at new depth; debounce 200ms (Mantine `useDebouncedValue`) to avoid thrashing during drag. The graph fades out via `Skeleton` overlay during refetch; no full remount (D-04). |
| React Flow `<Controls>` | Click zoom / fit | Native React Flow behavior. No app-level interception. |
| React Flow `<MiniMap>` | Click / drag | Native React Flow behavior — clicking centers the canvas on click point; dragging pans. |
| Browser back / forward | — | Respects history (D-16). `/explorer/Patient/abc/graph → click Encounter node → /explorer/Encounter/xyz` then back returns to `/explorer/Patient/abc/graph`, NOT `/explorer/Patient/abc`. |

### Keyboard

Phase 49 ships **NO new keyboard shortcuts**. The design handoff describes `1/2/3/4` mode-switch + `J` peek — both are out of scope (4-mode shell deferred). The depth slider supports its native arrow-key behavior (Mantine default).

The "Graph" button is keyboard-reachable via standard tab order (it's a Mantine `<Button>`; no custom handlers needed).

### Theme switch

`useMantineColorScheme().setColorScheme('dark')` triggers:
1. `<html data-mantine-color-scheme="dark">` updates.
2. `--mantine-color-*` CSS vars re-resolve at the browser layer.
3. `:global(.react-flow)` CSS-variable bridge (graph.module.css, D-11) re-resolves.
4. React Flow re-paints the canvas — **no React state change, no remount**.
5. The graph DOM root retains identity (verified by D-20 test #4).

### Loading sequencing

| Phase | UI |
|-------|-----|
| t=0: Route enters | Lazy chunk download (~83-91 KB gz). Mantine `<LoadingOverlay>` or React.lazy fallback (existing project pattern — researcher to confirm; if no precedent, use a single page-level `<Skeleton h="60vh" />`). |
| t≈100ms (cache hit) / 1-3s (cache miss): Chunk loaded | `<ResourceGraphView>` mounts. Toolbar renders immediately (depth slider visible at depth=1). Canvas shows 4-card `<Skeleton>` grid (D-12). |
| t+ ~200-1500ms: BFS fetches resolve | dagre runs synchronously (~5-15ms for typical graphs). React Flow renders nodes + edges with `fitView`. Skeleton fades out via Mantine default transition. |
| Theme switch | No re-fetch, no remount, just CSS-variable propagation (instant). |
