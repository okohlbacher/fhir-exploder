## Layout & Responsive Behavior

### Dashboard toolbar (S6 + S7 integration into `QualityOverviewPage.tsx:209-252`)

Current structure (line 209):

```tsx
<Group justify="space-between" align="flex-end">
  <Group gap="md" align="flex-end">
    <CohortSelector ... />       {/* becomes ResourceTypeSelector */}
    <SampleSizeControl ... />
  </Group>
  <Group gap="sm">
    {/* Last computed + 4 buttons */}
  </Group>
</Group>
```

Target structure:

```tsx
<Group justify="space-between" align="flex-end" wrap="wrap">
  <Group gap="md" align="flex-end" wrap="wrap">
    <ResourceTypeSelector ... />   {/* label: "Resource types", maxWidth 320 */}
    <ActiveCohortSelect ... />     {/* NEW, maxWidth 320 */}
    <SampleSizeControl ... />
  </Group>
  <Group gap="sm" wrap="wrap">
    <Text size="sm" c="dimmed">Last computed …</Text>
    <Button variant="light" leftSection={<IconUsersGroup size={16} />}>Manage cohorts</Button>
    {/* ...existing 4 buttons unchanged */}
  </Group>
</Group>
```

**Responsive behavior — explicit:**

- Both inner `<Group>` blocks gain `wrap="wrap"` (Mantine 8 default is `nowrap`; we opt in). Rationale: adding a 3rd control to the left group and a 5th button to the right group pushes horizontal density past what the current file handles; wrapping is the cleanest Mantine-native fallback.
- Outer `<Group justify="space-between">` stays `wrap="wrap"` so that at narrow widths the two inner groups stack vertically rather than horizontally-compressing.
- Each left-group control caps at `style={{ maxWidth: 320 }}` (already the case for `CohortSelector.tsx:27`). `SampleSizeControl` has no explicit cap — leave it unconstrained; Mantine `NumberInput` default sizes sensibly.
- No explicit `@mantine/hooks.useMediaQuery` breakpoint logic. The `wrap="wrap"` + `maxWidth` pair handles narrow widths reactively.
