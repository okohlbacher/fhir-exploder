<objective>
Fix the Sidebar's exact-match route activation bug so nested routes highlight their section root. Replace `location.pathname === link.href` at `Sidebar.tsx:97-115` (specifically lines 104 and 115 per RESEARCH.md §Focus 3) with React Router 7's `useMatch` hook using `end: false` for section roots and `end: true` for exact-match rows (Dashboard `/` and Cohorts `/quality/cohorts`).

**Committed product decision — Option B (Cohorts-only activation on `/quality/cohorts`):**

Per ROADMAP Phase 26 success criterion #3: _"Navigating to `/patients/123`, `/explorer/Patient/1`, or `/quality/plausibility/Observation` highlights the corresponding **section root** via `RouterNavLink`'s native `isActive`."_ The phrase "section root" implies exactly one active section, not two. On `/quality/cohorts` we therefore activate ONLY the Cohorts row — not Quality and Cohorts simultaneously. This also matches the principle of least surprise (single active nav item). RESEARCH.md §Pitfall 3 raised this as an open question; this plan resolves it to Option B and implements it unconditionally.

**Mechanism:** Extend the `NAV_ITEMS` array entries with an optional `exact?: boolean` field. `exact: true` causes `useMatch` to use `end: true` (self-only match). `exact: false` or undefined causes `end: false` (self + descendants match). Applied per-item:

| Row | `to` | `exact` | Rationale |
|-----|------|---------|-----------|
| Dashboard | `/` | `true` | `/` is a prefix of every route; MUST be exact-only. |
| Explorer | `/explorer` | `false` | Section root — must highlight for `/explorer/Patient/1`. |
| Patients | `/patients` | `false` | Section root — must highlight for `/patients/123`. |
| Quality | `/quality` | `false` | Section root — must highlight for `/quality/plausibility/Observation`. |
| Cohorts | `/quality/cohorts` | `true` | Sub-route — must NOT cause Quality to also activate; Cohorts is its own logical section in the sidebar. |

Because Cohorts has `exact: true`, `useMatch({ path: '/quality/cohorts', end: true })` matches only `/quality/cohorts`. And because Quality has `exact: false` with `path: '/quality'`, `useMatch({ path: '/quality', end: false })` WOULD match `/quality/cohorts` via descendant-match — this is the Pitfall 3 concern. We solve it by adding a second-pass guard at the Quality row: Quality's `useMatch` uses `end: false`, AND we subtract the Cohorts path with an additional `useMatch({ path: '/quality/cohorts', end: false })` check — if that Cohorts-descendant match exists, Quality's active state is suppressed. Concrete formula for Quality's row: `active = !!qualityMatch && !cohortsMatch`. This is the most-specific-wins rule made explicit, using only `useMatch` primitives.

Tiny plan — 1 source file + 1 new test file. Runs in Wave 2 parallel with Plan 26-02 (file-set disjoint).

Purpose: Eliminate the exact-match activation bug; navigate correctly highlights the most-specific section root for nested routes.
Output: Sidebar refactored with `exact` flag + most-specific-wins rule; Sidebar test file created.

  icon: Icon;

];

**SidebarRow composition (Option B most-specific-wins for Quality):**

```tsx
function SidebarRow({ item }: { item: NavItem }) {
  const match = useMatch({ path: item.to, end: item.exact ?? false });
  // Option B: suppress Quality section when a Cohorts descendant is active.
  const cohortsMatch = useMatch({ path: '/quality/cohorts', end: false });
  const active = item.to === '/quality'
    ? !!match && !cohortsMatch   // Quality: active UNLESS we're under /quality/cohorts
    : !!match;                   // everyone else: native useMatch result
  return (
    <NavLink
      component={RouterNavLink}
      to={item.to}
      label={item.label}
      leftSection={<item.icon size={20} />}
      active={active}
    />
  );
}
```

**Note on the Mantine NavLink + RouterNavLink composition:** Per RESEARCH.md §Focus 3, `@mantine/core`'s `NavLink` component with `component={RouterNavLink}` does NOT pass through `react-router`'s render-prop `isActive`. That's why we use the `useMatch` hook at the Sidebar row level instead of trying to read `isActive` from NavLink's render-prop.

Section roots per D-10: `/patients`, `/explorer`, `/quality`. Cohorts at `/quality/cohorts` is a sub-route and gets `exact: true` per the Option B commitment above.
